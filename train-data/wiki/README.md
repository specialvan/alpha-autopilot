# Personal Wiki Subset

This subdirectory documents the human-reference view of the `train-data` package.

## Purpose

Use this subset as a navigable personal wiki for:

- persona taxonomy
- legitimacy shells
- target gaps
- primitive / knife library
- scene fit patterns
- failure / recovery / upgrade logic
- state transition patterns
- compatibility relationships
- thinking-trace patterns
