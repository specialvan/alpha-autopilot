# 治理摘要

## 1. 项目主线

`alpha-autopilot` 的主线始终是小说章节智能推荐与写作辅助系统。

## 2. 三层结构

### Baseline
- `v1/v2`
- 稳定基线
- 仅允许维护性变更

### Increment
- `v3`
- 质量层、逆向拆解、训练增强、QC
- 作为独立增量推进

### Experimental
- 探索性方案
- 不直接影响主线默认行为

## 3. 当前治理目标

- 收口 `v1/v2`
- 收敛文档口径
- 正确表达 `v3` 的增量角色
- 防止路线图与状态文档分叉

## 4. Codex 执行要求

- 单次只做一个目标
- 改代码前先确认层级
- 变更后必须同步更新状态
- 允许灰度，不允许无门禁直改主线

## 5. 最重要的一句话

> 先收口基线，再推进增量；先定义门禁，再允许接入。
