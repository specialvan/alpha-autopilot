# Codex 运行指令卡

## 唯一优先级来源

- 详细执行顺序只引用 `README_FOR_CODEX.md`
- 本卡只保留执行摘要，不再单独定义步骤顺序

## 开工摘要

1. 先读 `CODEX_DEVELOPMENT_GOVERNANCE.md`
2. 再读 `claude_review_package/README_FOR_CODEX.md`
3. 再读 `claude_review_package/package_manifest.md`
4. 按 `README_FOR_CODEX.md` 判定任务层级并执行
5. 只做单一目标，避免跨层级扩张

## 2. 默认执行范围

默认只读取以下层级：

- `mainline`
- `increment`

只有在追溯历史问题时，才读取 `archive`。

## 任务判断规则

### Baseline
适用于：
- 稳定基线修复
- 兼容性维护
- 只影响当前已完成主线的调整

### Increment
适用于：
- `v3` 质量层
- 推荐增强
- 新评估能力
- 新 QC 能力
- 新工作台增强

### Experimental
适用于：
- 不确定方案
- 候选算法
- 试验性探索
- 暂不准备进入主线的内容

## 变更前检查清单

- 任务目标是否单一
- 是否会破坏 Baseline
- 是否有回滚路径
- 是否需要测试覆盖
- 是否需要同步状态文档
- 是否会让 `v3` 被误写成新主线

## 变更后必须做的事

- 更新对应状态文档
- 如有必要，补充风险说明
- 如有必要，补充归档提示
- 确认改动没有跨层级污染

## 禁止事项

- 不允许在无门禁情况下直改主线
- 不允许把实验方案写成默认方案
- 不允许把 `v3` 说成替代 `v2`
- 不允许同时扩大多个目标
- 不允许让历史评审文档反向定义当前路线

## 一句话原则

> 先判层级，再做变更；先保基线，再做增量；先能回滚，再考虑扩展。
