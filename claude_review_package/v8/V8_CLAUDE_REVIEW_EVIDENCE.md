# V8 Claude Review Evidence

> Purpose: 固化本轮对初始素材与反派建模底层结构的拆解结论，作为 v8 / v8.1 评审依据，避免后续在无证据前提下把 Claude 的拆解误判为“幻觉式发挥”。
>
> Scope: 本文档记录的是对初始素材的结构化提炼结果，不是现实操控指南，也不是可直接执行的行为建议。

## 1. 结论总览

本轮拆解已经把初始素材中的反派机制收束为一条完整链路：

- 人格底盘
- 合法性外壳
- 心理缺口
- 原语选择
- 场景适配
- 失手方式
- 恢复方式
- 升级触发
- 状态迁移
- 总闭环
- 场景—刀法—代价—失效条件矩阵

这说明 v8 的问题不在于“有没有依据”，而在于**还缺最后一层工程化收口**，需要把这些结构进一步落成可供 Codex 消化的 schema / selector / fallback 逻辑。

---

## 2. 人格底盘层（底层动因）

本轮从素材中提炼出的核心人格差异，不是简单的“会不会算计”，而是每类角色背后的匮乏结构不同：

- 傻白甜型：靠无害感获得进入权
- 性冷淡型：靠稀缺感维持价值
- 红颜型：靠精神共鸣进入核心位置
- 小三型：靠耐力与位置焦虑长期耗局
- 闺蜜型：靠熟悉感稀释边界
- 前女友型：靠未完成叙事回流
- 社交控场型：靠公开秩序和体面压位
- 系统派型：靠结构化布局与可预测性
- 经验派型：靠失败复盘与快速修正
- 本能派型：靠即时刺激和现场感

这部分对应后续工程里的 `core_wound`、`core_need`、`fear_structure`、`time_horizon` 等字段。

---

## 3. 合法性外壳层

反派并不是直接以“控制者”面目出现，而是通过一层可被接受的姿态把控制包装起来。素材中反复出现的外壳包括：

- 体贴
- 无害
- 理性
- 旧情
- 朋友
- 规矩
- 纯真
- 高级感
- 顺从

这些外壳的共同点是：它们不是装饰，而是**让操控动作显得合理**。如果外壳塌掉，动作就会被重新解释成“有目的”“在演”“在算”。

这部分对应后续工程里的 `legitimacy_shell`、`public_mask`、`social_surface`。

---

## 4. 心理缺口层

素材中的所有原语，最终都指向目标侧的某种缺口。最稳定的缺口包括：

- 保护欲
- 稀缺偏好
- 被理解需求
- 面子焦虑
- 熟悉感松懈
- 未完成感
- 稳定性需求
- 灵活偏好
- 即时刺激偏好
- 占有欲 / 占位焦虑

这意味着“原语是否有效”，不是取决于原语本身，而是取决于**目标是否真的有那个口子**。

这部分对应后续工程里的 `psychological_gap`、`target_vulnerability`、`defense_style`。

---

## 5. 原语与原语链层

本轮拆解确认，素材不是单点技巧集合，而是由一组可组合的控制原语构成。稳定原语包括：

- 伪造脆弱
- 自尊喂养
- 延迟索取
- 关系撤离
- 体面羞辱
- 记忆改写
- 温柔收编
- 场景借力
- 反馈回路
- 身体语言诱导
- 互动留白
- 关系重定义
- 让利设套

并且这些原语不是随机叠加，而是形成几类稳定链路：

- 保护欲链：伪造脆弱 → 自尊喂养 → 反馈回路 → 延迟索取
- 稀缺追逐链：关系撤离 → 留白 → 高级感 → 场景借力
- 精神绑定链：深聊 → 红颜型共鸣 → 温柔收编 → 反馈回路
- 位置回收链：延迟索取 → 让利设套 → 关系重定义 → 记忆改写
- 公共压位链：自尊喂养 → 高位同情 → 体面羞辱 → 社交控场

这部分对应后续工程里的 `preferredKnives`、`secondaryKnives`、`knife_compatibility`、`forbiddenMoves`。

---

## 6. 场景适配层

本轮明确：同样的原语，放在不同场景里，效果完全不同。场景需要拆成以下维度：

- 公开度
- 观众结构
- 权力结构
- 节奏压力

并进一步形成十类典型场景：

- 私密亲密场
- 半公开熟人场
- 公开社交场
- 资源争夺场
- 权力服从场
- 长期陪伴场
- 夜店 / 派对场
- 旧关系回流场
- 竞争围观场
- 转化收网场

这部分对应后续工程里的 `SceneContext`，以及更细的 observer topology、power topology。

---

## 7. 失手、修复、升级、状态迁移

本轮还明确了反派不是静态人格，而是一个会迁移的系统：

### 常见失手
- 外壳塌陷
- 节奏失控
- 位置锁死
- 解释权失败

### 修复方式
- 重新示弱
- 降低强度
- 退回熟人位
- 换场景
- 重修体面
- 重建解释权

### 升级方向
- 更隐蔽
- 更稀缺
- 更系统
- 更耐耗
- 更复杂
- 更会让别人替她解释

### 状态迁移链
- 无害
- 可疑
- 失信
- 修复尝试
- 局部恢复
- 升级
- 更隐蔽
- 更强
- 更僵
- 崩塌

这部分对应后续工程里的 `failure_mode`、`recovery_mode`、`upgrade_trigger`、`state_transition`。

## 8. 场景—刀法—代价—失效条件矩阵

本轮已经补齐了矩阵式收口，说明不同场景下，哪些刀法最有效、代价是什么、失效条件是什么。典型收口如下：

- 私密亲密场：伪造脆弱、温柔收编、延迟索取、关系撤离、反馈回路、互动留白
- 半公开熟人场：自尊喂养、圈层渗透、闺蜜型留白、体面型互动、反馈回路、场景借力
- 公开社交场：体面羞辱、高位同情、社交控场、社会证明、场景借力、自尊喂养
- 资源争夺场：让利设套、延迟索取、理性包装、关系重定义、记忆改写
- 权力服从场：高位同情、体面压制、规矩型外壳、解释权争夺
- 长期陪伴场：反馈回路、温柔收编、轻度依赖、留白、自尊喂养
- 夜店 / 派对场：身体语言诱导、场景借力、群体协同、高级感外壳、低压撩动
- 旧关系回流场：记忆改写、旧情型外壳、旧伤触发、未完成感、反馈回路
- 竞争围观场：体面羞辱、自尊喂养、社交控场、社会证明、叙事争夺
- 转化收网场：延迟索取、关系重定义、让利设套、记忆改写、身份合法化

每个场景同时明确了代价和失效条件，用于后续构建 scene selector 与 fallback policy。
