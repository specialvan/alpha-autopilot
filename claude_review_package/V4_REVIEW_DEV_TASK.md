# 给 Codex 的 V4 评审与开发任务说明

## 任务名称

V4 人物关系与性格驱动的剧情生成升级

## 任务背景

在 `v1/v2` 已完成稳定闭环、`V3` 已建立读者留存目标函数与生成控制层之后，剧情生成仍存在一个核心问题：

- 仍然容易把剧情当成“灵感瞎想”
- 仍然容易把剧情当成“套模板、填结构”
- 仍然容易出现卡文、断裂、没生命力的问题

基于新的 PR 需求，`V4` 要把剧情生成进一步上移到：

> 剧情不是编出来的，而是从人物关系的位移与人物性格在压力下的选择中长出来的。

这次需求的重点不是增加一个新标签，而是补上“剧情是如何自然长出来”的顶层抽象。

## 任务目标

请围绕以下目标进行评审与开发：

- 在不破坏 `v1/v2` 基线和 `V3` 留存控制层的前提下，追加 `V4` 人物关系与性格驱动的剧情生成机制
- 将人物关系差（地位差 / 信息差 / 情感差）抽象为可计算的冲突边界与剧情动力
- 将人物性格抽象为压力下的行动偏好与事件选择模型
- 将外部压力抽象为剧情发动机，驱动人物做出极端或高张力选择
- 支持从关系 + 性格 + 压力推导出多个自然长出来的剧情候选，并按留存目标排序

## 归属层判断

### 归属层

- [ ] Baseline
- [x] Increment
- [ ] Experimental

### 判断依据

- 这是在 `v1/v2` 与 `V3` 基础上的增量推进，不是替换基线
- 它会影响剧情推导、桥段生成、角色决策、留存控制联动，属于 `V4`
- 它不是试验性探索，而是明确的阶段性剧情生成升级
- 它不会改变 `v1/v2` 默认稳定路径，但会在 `V3` 之上增加新的剧情生成核心

## 需要 Codex 评审的重点

### 1. 剧情生成核心认知是否成立

请确认：

- 剧情是否被定义为“人物关系位移 + 人物性格选择 + 外部压力”共同作用的产物
- 是否明确拒绝“灵感瞎想”式或纯模板式生成
- 是否能够通过人物模型推导剧情而不是直接拍脑袋给结果

### 2. 人物关系模型是否合理

请确认：

- 是否至少包含地位差、信息差、情感差
- 是否能表达冲突边界、压迫反抗、悬疑反转、拉扯爽点
- 是否支持关系位移作为剧情推进信号

### 3. 人物性格模型是否合理

请确认：

- 是否能够表达人物在压力下的行动偏好
- 是否支持同一事件因性格不同而导出不同剧情桥段
- 是否避免人物性格漂移成“木偶”

### 4. 外部压力模型是否合理

请确认：

- 是否明确了断粮、威胁、羞辱、限时、利益争夺等压力源
- 是否能用压力放大人物选择的极端性
- 是否把压力作为剧情发动机而不是背景装饰

### 5. 剧情推导链路是否可落地

请确认：

- 是否能从人物关系 + 性格 + 压力推导剧情候选
- 是否能输出多个自然长出来的桥段
- 是否能把桥段按吸引力和留存目标排序
- 是否能与 `V3` 留存控制层联动

## 设计边界

### 允许做的事

- 追加人物关系模型
- 追加人物性格模型
- 追加外部压力模型
- 从关系 / 性格 / 压力推导剧情候选
- 与 `V3` 留存控制联动

### 不允许做的事

- 不允许破坏 `v1/v2` 默认稳定路径
- 不允许删除结构约束和留存约束
- 不允许把剧情生成改成纯规则模板
- 不允许把实验性桥段直接写成默认主线
- 不允许脱离人物关系与性格直接硬编剧情

## 回滚策略

- `V4` 推导层应可单独关闭或降级
- `V3` 的留存控制层必须继续可用
- `v1/v2` 默认路径必须保持可运行
- 任何新增人物模型或剧情推导规则都应保留回退到基础版本的能力

- 能从压力放大剧情爆发力
- 能输出多个自然长出的剧情候选

- `V3` 留存目标函数仍然有效
