# Claude 评审建议工程包

## 目的

本工程包用于让 Codex 按统一治理口径执行 `alpha-autopilot` 的后续开发与文档收敛工作。

当前项目采用三层结构：

- **Baseline**：`v1/v2` 稳定基线，只允许修复与兼容性维护
- **Increment**：`v3` 增量需求，独立推进、可灰度、可回滚
- **Experimental**：实验探索，不得直接影响主线默认行为

## 工程包包含内容

- 需求与路线总纲
- 项目状态与阶段进度
- 前端需求与前端状态
- 技术瓶颈与风险说明
- Codex 开发治理规范
- 深度方向漂移审计

## 使用方式

建议 Codex 按以下顺序执行：

1. 先阅读本包内的总纲与治理规范
2. 再阅读项目状态文档，确认当前真实边界
3. 按 baseline / increment / experimental 三层归类后再改代码
4. 任何新功能默认进入 `v3` 增量层，除非明确属于实验层
5. 所有变更必须同步更新状态文档

## 执行目标

- 收敛文档口径
- 防止 `v3` 被误解为独立主线
- 确保 `v1/v2` 稳定收口
- 让 Codex 的后续实现都服从统一的开发治理规则
