### 2.1 市场供需与题材选题（20250905）

**核心提炼**：爆款题材的本质是"把现实压抑用荒诞包装后卖给读者"。供需分析先于世界观构建，核心是捕捉"当代人共同被逼疯的经历"并用网文逻辑包装。  
**量化映射**：`A4 retention_trajectory_alignment` 在题材选择阶段就已经有参照系——同频道近期活书的留存曲线即 A4 的先验均值。  
**新指标贡献**：`A6 ip_flavor_corridor_delta` 的廊道上沿 = 现象级爆款的 NQM 均值；下沿 = 同频道中位线；选题时检验题材是否落在廊道内。  
**PR 映射** → **PR-AA-16**（见第 3 节）

### 2.2 期待感工程学（20250907）

**核心提炼**：网文的本质是"信息差驱动的期待感工程"。钩子分两层：信息钩子（我知道但先不告诉你）+ 情绪发动机（压抑到极限再释放）。经典公式：先憋屈 → 极限压缩 → 瞬间爆发。  
**量化映射**：  
- 信息钩子密度 → `T4 hook_density`（每 1000 字未解决悬念数）  
- 憋屈积累深度 → `T2 tension_gradient` 的负斜率段长度  
- 爆发强度 → `T5 climax_payoff_ratio`  
**决断规则**：若连续 5000 字 T4 < 0.3（钩子稀缺），触发"悬念注入"弹性干预，从平行世界提取一个未兑现悬念事件注入当前进程。  
**PR 映射** → PR-AA-01（RetentionDesireVector · INFORMATION_GAP 分支权重上调）

### 2.3 新手七步法（20250908）

**核心提炼**：七步结构化 —— 单条主线 / 热爱题材 / 熟悉场景 / 经典 CP / 一句话故事 / 风格选择 / 情节推进节奏。其本质是"约束复杂度"，为 AI 生成提供质量边界。  
**量化映射**：  
- 单条主线约束 → `P3 goal_alignment_ratio`（多主线时 P3 被稀释）  
- 一句话故事完整性 → `T1 six_step_coverage` 的宏观版本：整本书能否用"一个 X 为了 Y 做了 Z 遇到 M 最终 N"概括  
**新增 NQM 校验**：在书籍创建阶段引入"一句话故事压测"：LLM 尝试将当前大纲压缩为一句话，若失败则警告结构过散。  
**PR 映射** → PR-AA-02（PlotUnitScaffold 扩展：增加宏观故事一句话摘要字段 `story_logline`）

### 2.4 单元循环 + 三幕式（20250910）

**核心提炼**：  
- **核心循环**：脑洞（世界观）+ 点子（金手指）+ 梗（冲突点）= 故事骨架  
- **三幕式**：起因 → 经过 → 结果，且上一个故事的结果即下一个故事的起因（无限循环）  
- "黄金三章"= 用最快速度完成第一个三幕循环，把主角的挂/仇恨/爽点全砸出来  
**量化映射**：  
- 三幕式完整度 → `T1 six_step_coverage`（六步骨架是三幕式的精细化版本）  
- 循环衔接质量 → `W4 relationship_causality`（上一单元的结果作为下一单元起因的因果连续性）  
- 黄金三章质量 → `T8 opening_hook_composite`（独立门禁指标）  
**决断规则**：检测到三幕循环断裂（W4 < 0.4 且 T1 < 0.5）时，从平行世界提取衔接事件作为弹性注入。

### 2.5 仿写情绪内核（20250912）

**核心提炼**：真正值得仿写的不是剧情而是**情绪内核**。以斗破仓穹为例，内核是"世态炎凉"（你有用时被捧，无用时被踩）。仿写公式：找到**情绪引爆点**（角色从顶峰到谷底的转折节点）+ **极致前后反差**（捧得越高，摔得越狠）。  
**量化映射**：  
- 情绪引爆点清晰度 → `T2 tension_gradient` 的极值点检测  
- 前后反差幅度 → 新增计算：引爆点前 N 章 NQM_P1 均值 vs 引爆点后 N 章 NQM_P1 均值的差值  
- 内核一致性（全书情绪内核是否统一）→ `A6 ip_flavor_corridor_delta`（内核漂移会导致 A6 异常）  
**PR 映射** → PR-AA-10（种子提取器新增"情绪内核提取"字段：`emotional_core_type` + `trigger_point_chapter`）

### 2.6 爽感多巴胺机制（20250915）

**核心提炼**：爽感三招——  
1. **随机奖励**：不可预期比固定奖励上瘾 10 倍（开盲盒 > 打卡签到）  
2. **仪式感**：天降异象 / 全服公告 / 众人震惊（放大奖励的社会感知）  
3. **社交认证**：在人前获得 / 旁观者反应 / 对手嫉妒（爽感的本质是"别人知道你获得了"）  
**量化映射**：  
- 随机奖励密度 → **`T6 random_reward_density`**（新增，不可预期奖励占比，目标 > 0.6）  
- 社交认证强度 → **`T7 social_validation_score`**（新增，高潮场景见证者反应密度）  
**AC 定义**：  
- `T6`: 连续 3 章固定奖励（T6 < 0.2）→ 触发弹性注入，从平行世界随机抽取一个奖励事件替换当前固定奖励  
- `T7`: 高潮场景 T7 < 0.3（无见证者）→ 建议生成旁观视角段落作为备选

### 2.7 五大写作必杀技（20250916）

**核心提炼**：  
1. **催命符**（限制级目标）：给主角头上悬一把刀，再挂倒计时 → `P5 goal_urgency_index`  
2. **地狱级难度**：天灾+人祸+心魔三板斧 → `T9 antagonist_pressure_index`  
3. **勾魂夺命钩**：每章结尾必埋钩子 → `T4 hook_density` 的章末约束  
4. **骗局式反转**：从头到尾针对读者的惊天骗局 → `A5 reversal_quality_score`  
5. **穿越式伏笔**：能穿越百章的伏笔，精准在未来某刻命中 → `W3 foreshadow_fulfillment`  
**决断规则（章末钩子守卫）**：章节结尾前 300 字检测 T4（未解决悬念），若 T4 = 0，触发章末钩子生成建议（神秘物品 / 异常事件 / 灵魂拷问三选一）。  
**PR 映射** → **PR-AA-19**（章末钩子守卫，见第 3 节）

### 2.8 人物写活与代入感（20250918）

**核心提炼**：三层代入感——  
1. **感官代入**（主视角 70%+，通过主角眼睛看世界）→ `P7 viewpoint_consistency_score`  
2. **情感带入**（利用读者已有的情感记忆，DNA 动了）→ `T3 desire_vector_hit_rate`（VALUE_RECOGNITION 分支）  
3. **逻辑代入**（读者在逻辑上认同角色，不得不帮他）→ `P3 goal_alignment_ratio`  
**量化映射**：  
- **`P7 viewpoint_consistency_score`**（新增）：单章节内 POV 切换合法性，非法切换（无过渡的视角跳跃）每次扣 0.1 分  
- 上帝视角滥用检测：若同一自然段出现 2+ 个角色的内心描写 → 自动标记为 `POV_VIOLATION`

### 2.9 故事细胞分裂法（20250919）

**核心提炼**：  
1. **故事盒**：充满张力的核心矛盾（A 的欲望 vs B 的阻碍，拧紧发条）  
2. **三大引擎**：地点（剧情推进工具）+ 人物（四类功能配角）+ 动机（深化为原始本能级别）  
3. **冲突网**：主线矛盾（全书发动机）+ 支线矛盾（丰富织网，让主线拉紧）  
**量化映射**：  
- 故事盒张力 → P3（目标明确性）× T9（阻碍压制系数）的积  
- 冲突网密度 → `W5 conflict_layer_coverage`（外部/内部/命运三层）  
- 动机深度 → P5（urgency）× PR-AA-01 中 RetentionDesireVector 的 PRIMAL_DESIRE 分量  
**PR 映射** → PR-AA-02 扩展（PlotUnitScaffold 增加 `story_box` 字段：核心矛盾一句话描述）

### 2.10 晋江爆款开头（20250920）

**核心提炼**：三条铁律——  
1. 开头禁止大段背景设定，第一句话给出时间+地点+人物+状态  
2. 聚光灯法则：前三章主角唯一焦点，配角按功能出场  
3. 第一章必须有冲突：把最尖锐的矛盾直接扔到读者脸上  
**量化映射** → **`T8 opening_hook_composite`**（新增，复合评分）：

```
T8 = 0.25 × conflict_in_c1     # 第一章是否有实质冲突
   + 0.25 × protagonist_focus  # 主角是否第一焦点（配角数量 < 3）
   + 0.25 × goal_clarity       # 前三章主角目标是否明确
   + 0.25 × info_hook_present  # 开头是否存在未解信息差
```

**开头门禁**：T8 < 0.60 时，生成系统在第一章结束后暂停，输出"开头诊断报告"并触发 PR-AA-20 的十大毒点检查器。

### 2.11 四个爆款公式（20251210）

**核心提炼**：四步——  
1. **生产诉求**：制造认知失谐（不满足感），让读者产生"这不公平，不该是这样的"  
2. **给予希望**：给主角一个打破困局的确定性（挂）  
3. **能力解决**：阶梯式满足（温饱→小康→首富），每级对应读者心理阶段  
4. **延迟满足**：叠加困境法（解决一个立刻引出下一个更大的）  
**量化映射**：  
- 诉求强度 → T2（张力梯度）的负值段：主角被压得越低，诉求越强  
- 希望注入时机 → T6（随机奖励密度）：金手指出现的时机不能太早也不能太晚  
- 阶梯式满足 → P3 × P5 的乘积变化曲线（目标难度和紧迫感应同步升级）  
- 叠加困境 → W5 conflict_layer_coverage（每层冲突解决后立即引入新层）

### 2.12 写出力量感（20251211）

**核心提炼**：三招——  
1. **绝对动因**：不是"想变强"，是"不变强就死全家"（恐惧 > 欲望）  
2. **地狱级难度**：反派必须比主角强，主角胜利靠微小变数而非降智  
3. **代价机制**：获得力量必须付出代价，代价越惨烈力量感越真实  
**量化映射**：  
- 绝对动因强度 → P5（urgency）× PRIMAL_DESIRE（生存维度）  
- 难度悬殊 → T9（antagonist_pressure_index），低 T9（< 0.5）= 降智预警  
- 代价计量 → 新增计算：每次角色能力提升事件关联的"代价标注"覆盖率  
**PR 映射** → PR-AA-03 扩展（EmotionSliderMap 增加 `sacrifice_log`：每次能力跃升的代价记录）

### 2.13 顶级反派塑造（20251213）

**核心提炼**：三种模板——  
1. **布局者**：信息差 + 棋局观，计划 A 失败是计划 B 启动的前提  
2. **殉道者**：逻辑自洽的歪理，让读者"虽然他坏但他说的有道理"  
3. **你太者**：藏在身边的阴影，知己知彼式背刺  
**量化映射**：  
- 布局者 → `A3 event_causality_coherence`（反派行动的多重目的覆盖率）  
- 殉道者 → `P4 function_type_fidelity`（CONFLICT 类型的动机逻辑自洽评分）  
- 你太者 → `P4`（DISGUISE 类型的双层关系分离存储，PR-AA-04）

### 2.17 冲突底层逻辑（20251222）

**核心提炼**：冲突 = 强烈目标 + 难以逾越的障碍。三层维度：

**量化映射** → **`W5 conflict_layer_coverage`**（新增）：

## 7. Codex 评审四维度检查清单（V7 专项）

### 7.1 代码质量
- NQMSampler（PR-AA-18）必须是纯 utility 层，不依赖任何 domain 层，可独立测试
- P 层计算（P1/P2/P7）使用向量运算，禁止 LLM 调用（控制成本）
- 决断路由规则（第 4 节 R-01~R-10）以配置文件形式管理，不硬编码在业务逻辑中

### 7.2 功能完整性
- PR-AA-18 的 28 维 AC 均可通过自动化测试验证，不依赖主观判断
- PR-AA-22 的死锁检测条件需有足够的连续章节样本才能触发，避免误报（最小 3 章窗口）
- PR-AA-23 的基准阈值更新需要记录更新前后的阈值变化，供审计

### 7.3 稳定性
- PR-AA-17 的开头门禁"忽略（作者确认）"选项必须有日志记录，不能静默通过
- PR-AA-22 的自动破局路由在所有 4 种策略均失败时需要 fallback（人工介入通知）
- T9 降智预警（R-07）触发后必须等待作者确认才继续生成，不允许自动绕过

### 7.4 部署运维
- NQM-V7 引入 LLM-as-judge 的指标（T5/T7/T8/T9/T10）需记录单独的 token 消耗，接入 T04 告警体系
- PR-AA-23 基准库需要备份策略（拆书样本是核心资产）
- A6 廊道参数在书籍创建后不允许自动更新（防止漂移），仅通过 PR-AA-23 手动触发
