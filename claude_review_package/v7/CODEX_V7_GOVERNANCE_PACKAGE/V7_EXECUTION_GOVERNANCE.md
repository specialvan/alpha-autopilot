# V7 Execution Governance

## 1. 执行原则

- 单次只做一个清晰目标。
- 先判断层级再改代码。
- 先写回滚路径再放量。
- 先有证据再宣称完成。

## 2. 任务优先级

1. 基线稳定性问题
2. V7 P0 主链能力
3. V7 P1 风控与守卫
4. V7 P2/P3 工具化增强
5. 实验性探索

## 3. 文档同步要求

- 需求边界变动：更新 V7 计划文档。
- 状态变化：更新状态与验收记录。
- 新冲突发现：记录裁决与归档策略。

## 4. 审计输出最小集合

- 变更摘要
- 影响面清单
- 测试结果
- 回滚结果
- 风险与后续动作
