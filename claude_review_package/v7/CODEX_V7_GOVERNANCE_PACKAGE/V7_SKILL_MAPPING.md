# V7 Skill Mapping

## 1. 输入 skill

- `project-governance-template`
- `project-init-governance-template`

## 2. 映射逻辑

- 既有项目治理（template）负责：分层控制、门禁、执行规约、文档裁决。
- 初始化治理（init template）负责：启动路径、模板化输入、标准流程、最小工程包。

先走 `V7_START_HERE.md`，再按 `V7_CODEX_DEVELOPMENT_GOVERNANCE.md` 约束执行，所有新任务必须先过 `V7_REQUIREMENT_INTAKE_TEMPLATE.md`。
