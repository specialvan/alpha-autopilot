# CODEX V7 Governance Package

## 1. 目的

本工程包用于 `alpha-autopilot` 的 V7 开发治理，基于以下两个 skill 的组合思路整理：

- `project-governance-template`（既有项目治理接管）
- `project-init-governance-template`（治理先行初始化）

目标是让 Codex 在 V7 开发中始终满足：可分类、可测试、可回滚、可审计。

## 2. 适用范围

- 适用层级：V7 相关增量开发（Increment）
- 不适用：直接改写 `v1/v2` 基线路径
- 不适用：未门禁的实验性默认接入

2. `V7_CODEX_DEVELOPMENT_GOVERNANCE.md`
