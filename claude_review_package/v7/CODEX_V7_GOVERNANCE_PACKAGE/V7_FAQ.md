# V7 FAQ

## Q1: V7 是不是可以直接改 `v1/v2`？

不是。V7 属于 Increment，默认不能直接改写基线默认路径。

## Q2: 评审文档能不能直接当需求边界？

不能。评审用于审计与准入建议，需求边界以治理规范和主计划文档为准。

## Q3: V7 新需求如何快速归类？

先用 `V7_REQUIREMENT_INTAKE_TEMPLATE.md`，再映射到 `PR-AA-26 ~ PR-AA-39`。

## Q4: 什么情况下必须回滚？

- 基线回归失败
- 守护指标明显退化
- 门禁能力误阻断且无快速修复路径

## Q5: 如果没有真实线上读者数据怎么办？

可先用对标样本和代理指标做离线评估，但必须标记为低置信度并保留降级路径。

## Q6: Lite 与 Full skill 怎么选择？

V7 当前建议按 Full 思路执行；Lite 适合快速探索或临时子任务。
