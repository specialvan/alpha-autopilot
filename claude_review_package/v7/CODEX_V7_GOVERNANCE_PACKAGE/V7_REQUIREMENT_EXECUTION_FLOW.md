# V7 Requirement Execution Flow

## 1. 入口阶段

1. 需求登记（Intake Template）。
2. 归类到 `PR-AA-26 ~ PR-AA-39`。
3. 确认影响面和回滚路径。

## 2. 设计阶段

1. 明确模型与数据契约。
2. 明确配置开关与默认行为。
3. 固化测试计划和验收标准。

## 3. 实施阶段

1. 先 schema，再 service，再 route，再 test。
2. 每次只推进单目标，不跨层扩张。
3. 风险点提前写入执行记录。

## 4. 验证阶段

1. 单测通过。
2. 集成通过。
3. 基线回归通过。
4. 离线评估通过。

## 5. 退出阶段

1. 准备证据包（测试/评估/回滚演练）。
2. 同步状态文档。
3. 标记可合入候选或回退修复。
