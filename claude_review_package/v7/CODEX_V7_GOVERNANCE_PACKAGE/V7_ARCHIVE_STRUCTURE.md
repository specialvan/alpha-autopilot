# V7 Archive Structure

## 1. 归档目标

将历史评审与过期方案与当前执行主线分离，避免旧文档反向污染 V7 决策。

## 2. 分层建议

- `mainline`：当前执行依据
- `increment`：V7 当前迭代材料
- `experimental`：试验方案
- `archive`：历史与过期材料

## 3. V7 归档规则

- 评审草稿被新版本替代后进入 `archive`。
- 冲突文档保留快照，禁止直接删除。
- 归档文档不得再作为 Codex 默认启动输入。

## 4. 触发归档的条件

- 同主题文档已有更高版本并完成评审。
- 文档内容与最新治理规则冲突。
- 仅具历史记录价值，不再指导实现。
