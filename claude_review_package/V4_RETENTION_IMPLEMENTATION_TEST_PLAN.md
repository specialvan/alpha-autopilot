# V4 剧情推导与留存联动测试计划

## 1. 测试目标

验证 V4 的人物关系、人物性格与外部压力推导链路是否成立，并且能与 V3 的留存目标函数联动，同时不破坏 V1/V2/V3 的稳定路径。

## 2. 测试范围

### 2.1 人物关系模型

验证：

- 地位差、信息差、情感差是否可表达
- 关系位移是否能形成冲突边界
- 关系张力是否能被量化

### 2.2 人物性格模型

验证：

- 性格是否能表达压力下的行动偏好
- 同一事件在不同性格下是否能导出不同桥段
- 性格是否会漂移成没有决策偏好的木偶

### 2.3 外部压力模型

验证：

- 断粮、威胁、羞辱、限时、利益争夺等压力是否可表达
- 压力是否能放大人物选择极端性
- 压力是否能成为剧情发动机

### 2.4 剧情推导链路

验证：

- 是否能从关系 + 性格 + 压力推导剧情候选
- 是否能生成多个自然长出来的候选
- 是否能解释候选为什么成立
- 是否能与 V3 留存排序联动

### 2.5 回归与稳定性

验证：

- V3 留存控制层仍然可用
- V1/V2 默认路径不受影响
- V4 推导层可关闭、可降级、可回退

## 3. 推荐测试类型

### 3.1 单元测试

适合验证：

- 关系差值计算
- 性格选择推导
- 压力等级评估
- 剧情候选生成

### 3.2 集成测试

适合验证：

- 关系 / 性格 / 压力三者联动生成剧情候选
- 候选结果写入工作台上下文
- 与 V3 留存排序联动

### 3.3 回归测试

适合验证：

- 旧 V3 流程未被破坏
- 旧 V2 工作台和基础路由仍然可用
- 关闭 V4 后系统退回到 V3 路径仍正常

### 3.4 验收测试

适合验证：

- 系统是否能把剧情从“想出来”升级为“长出来”
- 是否能输出多个自然桥段候选
- 是否能解释关系 / 性格 / 压力如何影响结果

## 4. 建议用例

### 4.1 关系样本

- 地位压制关系
- 信息不对称关系
- 情感拉扯关系
- 利益冲突关系

### 4.2 性格样本

- 暴躁型
- 隐忍型
- 务实型
- 高风险偏好型
- 控场型

### 4.3 压力样本

- 断粮
- 威胁
- 公开羞辱
- 限时
- 资源争夺

### 4.4 组合样本

- 高压 + 暴躁型 + 地位压制
- 信息差 + 隐忍型 + 限时
- 情感差 + 务实型 + 利益争夺

## 5. 验收门槛

### 功能门槛

- 关系、性格、压力能分别进入推导链路
- 能生成多个剧情候选
- 能输出解释
- 能与 V3 排序联动

### 稳定性门槛

- V1/V2/V3 不被破坏
- 推导层可关闭
- 主线仍可运行

### 文档门槛

- V4 目录内文档完备
- 与 V3 目录不混用
- Codex 阅读路径清晰

## 6. 一句话总结

> V4 测试的核心是证明：人物关系、人物性格和外部压力可以稳定推导出多个自然剧情候选，并与 V3 留存目标联动，而不是靠灵感拍脑袋。
