# V3 读者留存目标函数与生成控制说明

## 1. 阶段定位

`V3` 属于 `Increment` 层，用于在不破坏 `v1/v2` 基线稳定性的前提下，追加一个新的顶层目标：

> 让系统不只是生成“结构正确”的内容，而是生成“更能留住读者继续读下去”的内容。

本阶段不是推翻现有结构能力，而是把结构能力升级为留存驱动能力。

## 2. 为什么需要这一层

现有 `v1/v2` 已经完成了：

- 推荐/规划闭环
- 结构化写作辅助
- 章节状态与上下文组织
- 基础质量与工作台能力

但它们尚未把“读者留存”作为最高层目标函数。结果可能出现：

- 结构完整，但不够抓人
- 标签很多，但只是装饰
- 情绪、节奏、爽点被当成描述项，而不是决策项
- 生成结果像模板填充，而不是持续吸引读者

因此 `V3` 的目标不是替代 `v2`，而是把“吸引读者”显式化为系统的上层控制目标。

## 3. 顶层目标函数

### 3.1 核心目标

`V3` 的核心目标函数定义为：

> 在满足结构正确、风格一致、信息可控的前提下，最大化章节对读者的持续吸引力与继续阅读意愿。

### 3.2 目标拆分

该目标函数可拆成以下可控维度：

- 情绪推进
- 节奏推进
- 爽点密度
- 悬念保持
- 冲突增长
- 角色吸引
- 章节钩子
- 信息释放节奏

### 3.3 目标优先级

`V3` 的生成优先级应从“结构优先”调整为：

1. 留存优先
2. 结构约束
3. 风格一致
4. 事实/世界观一致
5. 局部模板约束

也就是说，结构不是目的，而是服务于留存。

## 4. 生成控制层

### 4.1 角色

生成控制层负责把顶层目标函数转成实际的生成决策。

它决定：

- 这段内容应不应该加压
- 这段内容应不应该延迟揭示
- 这段内容应不应该提前给钩子
- 这段内容应不应该增加爽点
- 这段内容应不应该压缩说明
- 这段内容应不应该强化冲突

### 4.2 生成控制输入

生成控制层至少应接收：

- 章节上下文
- 角色状态
- 事件状态
- 风格状态
- 读者留存目标
- 当前章节阶段
- 前后章节关系
- 风险约束

### 4.3 生成控制输出

生成控制层至少应输出：

- 本章目标倾向
- 情绪曲线建议
- 节奏调整建议
- 爽点布局建议
- 悬念保留建议
- 冲突推进建议
- 章节结尾钩子建议

## 5. 标签体系的重定义

现有大量量化标签不应只是“描述字段”，而应升级为“决策变量”。

### 5.1 从描述到决策

例如：

- 情绪强度 -> 决定当前段落是推进、缓冲还是爆发
- 节奏密度 -> 决定信息释放速度
- 爽点间隔 -> 决定何时安排关键回报
- 悬念长度 -> 决定信息延迟程度
- 冲突增幅 -> 决定是否继续加压
- 章节钩子 -> 决定结尾是否必须留尾巴

### 5.2 标签使用原则

- 标签必须影响排序或生成
- 标签不能只用于展示
- 标签必须能被验证
- 标签必须可回写到评估体系

## 6. 与 `v1/v2` 的关系

### `v1/v2`

- 负责基础闭环与稳定工作台
- 负责结构化推荐和现有辅助能力
- 保持当前可用与可维护

### `V3`

- 在不破坏 `v1/v2` 的前提下增加留存目标函数
- 提升生成控制层的表达能力
- 让情绪、节奏、爽点等维度真正参与决策

`V3` 不是替代 `v2`，而是为 `v2` 追加更高层的写作目标函数。

## 7. 建议的 `V3` 开发方向

### 7.1 目标函数层

- 定义留存优先的目标函数
- 定义各标签的权重与约束
- 定义不同题材/阶段下的动态权重

### 7.2 生成控制层

- 增加生成前的控制决策
- 将标签影响映射到章节建议
- 支持钩子、节奏、爽点的显式控制

### 7.3 评估层

- 加入“继续阅读意愿”代理指标
- 加入章节吸引力评分
- 加入留存相关的局部验证指标

### 7.4 反馈层

- 将实际效果反馈到标签权重
- 将读者反馈或模拟反馈写回策略
- 对低吸引力片段进行重排或重写建议

## 8. 验收标准

`V3` 至少应达到：

- 不破坏 `v1/v2` 基线行为
- 能把留存作为显式目标
- 能让情绪/节奏/爽点等标签参与决策
- 能输出可解释的生成控制建议
- 能与现有工作台和训练链路逐步接入

## 9. 风险提示

- 不要把留存目标做成单一模板规则，否则会再次生成八股文
- 不要删除结构约束，否则生成会失控
- 不要让标签只停留在展示层
- 不要直接替换 `v2`，必须通过 `Increment` 方式逐步接入

## 10. 一句话总结

> `V3` 的任务不是推翻现有小说写作辅助，而是把“留住读者”变成顶层目标函数，并把情绪、节奏、爽点等标签升级为真正影响生成的控制变量。
