# 给 Codex 的 V3 评审与实现指令

## 任务目标

请评审并实现 `V3` 读者留存目标函数与生成控制层升级，确保系统从“结构正确”升级为“更能留住读者继续阅读”。

## 任务范围

本次任务属于 `Increment`，只允许在 `v1/v2` 基线之上追加能力，不允许推翻基线或把项目改成纯模板生成器。

### 允许做的事

- 追加留存目标函数
- 追加生成控制层
- 重定义情绪、节奏、爽点、悬念、冲突、钩子等标签的作用
- 增加留存导向评估与反馈
- 接入 `V3` 到训练/工作台/上下文链路的增量部分

### 不允许做的事

- 不允许破坏 `v1/v2` 默认稳定路径
- 不允许删除结构约束
- 不允许把系统改成单纯模板或八股规则引擎
- 不允许把实验性方案直接写成默认主线

## 需要 Codex 重点评审的问题

1. 顶层目标函数是否明确定义为“留住读者”
2. 生成控制层是否能真正影响决策，而不是只做展示
3. 标签体系是否从描述字段升级为决策变量
4. 是否保留了结构正确、风格一致、事实可控这些约束
5. 是否能对不同题材、不同章节阶段做动态调权
6. 是否有留存导向的评估、反馈与回写机制
7. 是否保留 `v1/v2` 可回滚能力

## 推荐实现顺序

1. 先落定义：目标函数、控制层、标签映射
2. 再落评估：留存代理指标、章节吸引力评分
3. 再落反馈：将效果回写到权重和策略
4. 再接链路：工作台、训练、上下文、展示
5. 最后补测试：单元、集成、回归、验收

## 验收标准

### 功能验收

- 系统能把“留住读者”作为显式目标
- 情绪/节奏/爽点等标签会影响生成建议或排序
- 输出更偏向“吸引继续阅读”而不是“套模板”

### 稳定性验收

- `v1/v2` 不受影响
- 新控制层可关闭、可降级、可回退
- 结构约束仍然保留

### 文档验收

- 路线图、任务清单、状态文档已同步
- 评审入口已同步
- 新增能力的边界已写清楚
