# V4 人物关系与性格驱动的剧情生成规格

## 1. 阶段定位

`V4` 属于 `Increment` 层，在 `V1/V2` 基线稳定、`V3` 留存目标函数与生成控制层已经建立的前提下，继续向上追加一层新的剧情生成核心：

> 剧情不是靠灵感瞎编出来的，而是从“人物关系的位移”与“人物性格在压力下的选择”中长出来的。

`V4` 的目标不是替代 `V3`，而是在留存驱动的基础上，把“剧情如何生成”进一步抽象成可计算、可控制、可解释的关系与性格推导机制。

## 2. V1 / V2 / V3 / V4 的关系

### V1 / V2

- 负责稳定闭环、结构辅助、工作台和基础推荐
- 解决“能不能跑通”“能不能稳定用”的问题

### V3

- 负责读者留存目标函数
- 负责生成控制层
- 让情绪、节奏、爽点、悬念、冲突、钩子等标签真正参与决策
- 解决“怎么更能留住读者”的问题

### V4

- 负责人物关系与人物性格驱动的剧情生成
- 负责把剧情从“想出来”升级为“长出来”
- 解决“剧情为什么会自然产生、为什么不会卡文”的问题

## 3. V4 核心认知

### 3.1 剧情不是灵感产物

V4 的核心立项认知是：

- 剧情不是灵感瞎想出来的
- 剧情不是套公式套出来的
- 剧情是从人物关系与性格互动中推导出来的

### 3.2 剧情的两大来源

#### A. 人物关系

人物关系决定冲突边界，典型差值包括：

- 地位差
- 信息差
- 情感差

这些差值会自然产生：

- 压迫与反抗
- 悬疑与反转
- 拉扯与爽点
- 仇恨、依赖、误解、利用、背叛、救赎等关系位移

#### B. 人物性格

人物性格决定事件走向。人在压力下会做出不同选择，因此同一个事件，在不同性格下会长出不同剧情：

- 暴躁型主角可能正面反击
- 隐忍型主角可能蓄势反杀
- 务实型主角可能先算账再反制
- 复杂型主角可能先接受表面羞辱，再利用关系与身份差反制

### 3.3 压力是剧情发动机

没有压力，人物不会做出极端选择，也就不会长出足够炸裂的剧情。

所以 V4 必须显式管理：

- 外部压力
- 关系压力
- 情绪压力
- 选择压力
- 目标压力

## 4. V4 的目标函数

V4 的目标函数不是“写出一段情节”，而是：

> 给定人物关系、人物性格与外部压力，推导出最自然、最有张力、最能持续推进的剧情走向。

### 4.1 子目标

- 让剧情从关系差中自然长出
- 让剧情从性格选择中自然长出
- 让事件走向可解释、可推导、可复用
- 减少卡文与硬编剧情
- 提高桥段的爆发力、连续性与生命力

## 5. V4 需要抽象的关键对象

### 5.1 人物关系模型

必须能表达：

- 地位差
- 信息差
- 情感差
- 利益冲突
- 依赖与控制
- 信任与背叛
- 资源不对称
- 目标冲突

### 5.2 人物性格模型

必须能表达：

- 冲动 / 冷静
- 隐忍 / 直接
- 务实 / 理想化
- 强势 / 退让
- 自保 / 牺牲
- 进攻 / 防守
- 控场倾向
- 风险偏好

### 5.3 外部压力模型

必须能表达：

- 断粮
- 催债
- 威胁
- 公开羞辱
- 生死压力
- 限时压力
- 利益争夺
- 关系破裂

## 6. V4 的生成链路

建议链路如下：

1. 识别当前人物关系
2. 识别当前人物性格
3. 识别当前外部压力
4. 推导可行动作空间
5. 根据性格选择最可能动作
6. 根据关系差生成冲突 / 拉扯 / 反转
7. 根据压力强度放大剧情张力
8. 输出最优剧情走向与桥段建议

## 7. V4 的核心能力

### 7.1 剧情推导

不是直接生成“结果”，而是先推导“人物在这种关系和压力下会怎么选”。

### 7.2 桥段长出

同一个前提可以长出多个自然桥段，系统需要能排序这些桥段，而不是只给一个拍脑袋答案。

### 7.3 防卡文

当剧情干了、人物不动了时，系统要能检查：

- 人物性格是否不稳定
- 人物关系是否过于静止
- 外部压力是否不足
- 冲突边界是否过窄

## 8. V4 的推荐开发方向

### 8.1 关系层

- 建立人物关系图谱
- 定义关系差值
- 定义关系位移事件

### 8.2 性格层

- 建立人物性格向量
- 定义性格在压力下的决策偏好
- 定义相同行为在不同性格下的差异化输出

### 8.3 压力层

- 建立外部压力模型
- 定义压力等级与剧情爆发阈值
- 支持高压驱动的桥段生成

### 8.4 剧情推导层

- 从关系 + 性格 + 压力推导剧情候选
- 对候选桥段进行吸引力排序
- 接入 V3 的留存控制层

## 9. 与 V3 的关系

V3 解决的是：

- 怎么更留人
- 节奏怎么控
- 爽点怎么布置
- 留存怎么提升

V4 解决的是：

- 剧情为什么会自然产生
- 人物为什么会做出某个选择
- 桥段为什么会往这个方向长

两者关系是：

> V3 决定“写得抓不抓人”，V4 决定“剧情是不是从人和关系里长出来的”。

## 10. 风险提示

- 不要把 V4 做成纯规则拼接，否则会再次变成模板
- 不要脱离 V3 留存目标函数，否则剧情再自然也未必抓人
- 不要把人物关系写死，否则剧情失去生长空间
- 不要把人物性格写死，否则人物会变成木偶
- 不要把压力弱化，否则剧情难以爆发

## 11. 验收标准

- 系统能从人物关系推导剧情张力
- 系统能从人物性格推导事件走向
- 系统能识别剧情卡死的根因
- 系统能给出多个自然长出来的桥段候选
- 系统能与 V3 的留存控制层联动
- 系统不破坏 V1/V2 的稳定路径

## 12. 一句话总结

> V4 不是继续“想剧情”，而是把剧情生成升级为：在人物关系、人物性格和外部压力的共同作用下，让剧情自然长出来，并且仍然服务于读者留存。
