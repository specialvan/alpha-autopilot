# alpha-autopilot Codex Review

本目录收纳给 DeepWiki 与后续团队协作使用的仓库说明草案。

- `alpha-autopilot-repo-notes.md`
  长版仓库说明，覆盖项目目标、模块地图、关键接口、关键流程、依赖与待确认项。
- `alpha-autopilot-interface-doc-outline.md`
  适合落到仓库根目录或 `docs/` 下的接口文档大纲建议。
- `alpha-autopilot-repo-notes-short.md`
  6 到 10 条短版 repo notes，可直接整理进 `.devin/wiki.json` 一类配置。
