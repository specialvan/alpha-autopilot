# 第二阶段实施清单

## 1. 阶段目标

第二阶段聚焦系统稳定化与扩展化，目标是把第一阶段形成的原型闭环继续推进到更稳定、更可维护、更接近生产可用的工程形态。

## 2. 第二阶段优先级

1. 冻结核心数据契约
2. 扩充样本与评估基础
3. 增强前后端工程化展示
4. 强化训练与反馈闭环
5. 为第三阶段价值进化预留接口

## 3. 任务拆解

### 3.1 冻结核心数据契约
- 明确 `StoryState` 的字段边界
- 明确推荐结果结构
- 明确训练结果结构
- 明确反馈请求响应结构
- 明确前后端字段命名规范

#### 验收标准
- schema 不再频繁漂移
- 前后端联调不因字段变更而反复返工

### 3.2 扩充样本与评估基础
- 增加题材样本
- 增加风格样本
- 增加阶段样本
- 增加失败样本和边界样本
- 建立推荐价值记录结构
- 建立推荐价值持久化
- 建立训练日志历史读取
- 建立历史轨迹接口

#### 验收标准
- 样本覆盖面明显提升
- 推荐训练不再依赖单一局部样本
- 价值记录可以落盘保存与读取
- 训练日志可以回放历史
- 前端历史轨迹直接读取真实接口

### 3.3 强化工程化展示
- 增加训练结果历史对比
- 增加版本切换
- 增加推荐预览对比
- 增加调参反馈可视化
- 增加章节建议模板切换
- 增加价值趋势图
- 增加版本对比与反馈摘要
- 增加历史轨迹面板

#### 验收标准
- 前端工作台具备更明显的操作和复盘能力

### 3.4 强化训练与反馈闭环
- 记录反馈后的版本变化
- 记录训练后的版本快照
- 记录推荐后的长期价值指标
- 建立基础价值记录结构
- 支持价值日志读取与趋势分析
- 训练与反馈完成后自动落盘

#### 验收标准
- 能看到每次训练和反馈的变化结果
- 能为第三阶段价值进化提供数据基础

## 4. 本阶段产出
- 更稳定的数据契约
- 更丰富的样本集
- 更清晰的训练反馈闭环
- 更工程化的前端展示
- 为第三阶段推荐价值进化预留接口

## 5. 与第三阶段的衔接

第二阶段只负责把基础打牢，不直接做完整的推荐价值自适应进化，但会提前预留：

- 价值记录字段
- 推荐模式标签
- 版本级对比入口
- 长期收益统计结构
- 价值记录持久化与读取能力
- 历史轨迹接口

这样第三阶段可以在较稳的基础上，直接进入价值进化层开发。
