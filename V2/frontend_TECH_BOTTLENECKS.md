# 前端技术瓶颈与复盘记录

## 1. 当前仍以静态数据为主

### 问题
页面已经支持 API 回退联动，但当前仍主要依赖本地回退数据。

### 影响
- 无法展示真实训练结果变化
- 无法体现在线推荐波动

### 应对
- 后续接入后端真实 `/api/dashboard`
- 建立可刷新状态源

## 2. 组件化尚未完全下沉

### 问题
虽然已拆分为多个组件，但仍处于页面级拆分阶段。

### 影响
- 复用性可以继续提升

### 应对
- 后续继续拆分更小粒度组件
- 抽离面板容器与展示单元

## 3. 数据契约需要继续冻结

### 问题
前后端字段需保持完全一致，避免接口漂移。

### 影响
- 后续联调可能出现字段偏差

### 应对
- 维持统一术语表
- 将前端 types 与后端 schema 对齐

## 4. 交互还偏少

### 问题
当前仍以信息展示为主，交互有限。

### 影响
- 难以体现推荐引擎的动态特性

### 应对
- 补充版本切换、样本切换、推荐触发等交互
